
This project is a refactoring of a Yatzy game made by Dalila and Yolanda, students of 1º DAM.

The original Yatzy code was difficult to read and had many repeated parts.
Our work was to clean the code, organize the functions, fix indentation problems, and replace magic numbers with constants.
We did not change the rules of the game. We only improved the structure to make it clearer and easier to understand.
